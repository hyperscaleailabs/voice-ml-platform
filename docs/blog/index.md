# Blog

Notes on building an ML platform for voice agents: the progression from a
single-laptop prototype to a system that trains, evaluates, serves and ships
models, and the design decisions that only become visible once latency is
something a user *hears*.

Posts follow the same evidence rule as the rest of this documentation.
Measurements from the private predecessor project are cited as "alpha-core,
cycle 5, 2026-09-12, `<file>`" and are never presented as this repository's
benchmark. Anything that has not been run says so.
